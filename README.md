# Checkpoints
CheckPoints is an app built to help gamers manage their game save files.
With automated backups, Git-powered version tracking, and online storage integration, it ensures your progress is never lost.
Dive into your save file history with a visual timeline of changes including branching, merging, and commit-level comparisons.
